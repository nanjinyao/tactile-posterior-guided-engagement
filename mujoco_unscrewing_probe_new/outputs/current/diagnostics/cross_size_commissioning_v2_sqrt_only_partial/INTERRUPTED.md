# Interrupted scaling-only diagnostic

This development-only run was deliberately stopped after two completed poses.
It showed that square-root time scaling reduced the M10 post-terminal-rejection
raw impulse but did not keep it below the unchanged 20 N hard limit.  It is
retained as negative diagnostic evidence and is not a complete evaluation.

The follow-up commissioning-v2 run additionally distinguishes a terminal-set
dwell retry from a capture-loss recovery: first entry into the CAD depth band
is held in place instead of triggering a retract/re-touch impact.

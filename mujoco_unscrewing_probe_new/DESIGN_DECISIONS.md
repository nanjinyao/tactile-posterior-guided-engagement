# Design Decisions

This file records scoped decisions for the clean project path. It is not a
chronological diary; each entry should clarify a fork where several plausible
technical routes existed.

---

## 2026-07-09 23:23 +08 - ChatGPT Roadmap vs M8-First Implementation

### Context

A ChatGPT discussion proposed a broad MuJoCo and experiment plan that included:

- M8/M10/M12 Allen socket-head modeling.
- source-style visual + 5 N spiral + 0.1 Nm torque baseline.
- clearance / micro-chamfer sweeps.
- geometry-aware spiral planning.
- contact support-area / pressure-center reasoning.
- conical / tilt / nutation probing.
- active contact geometry estimation and information-gain action selection.

The latest meeting, however, emphasized a narrower immediate need:

```text
Make the pipeline concrete:
how data is sampled, how labels are defined, what model is trained,
where the results are, and how the classifier connects to conservative actions.
```

### Decision

Use the ChatGPT plan as a roadmap, but implement the new project as:

```text
M8-first source-canonical Allen engagement benchmark
-> explicit visual-error initial offset sampling
-> action-conditioned F/T data
-> contact-state / probe-outcome classifier
-> conformal or set-valued uncertainty
-> hard-safety-gated rule recovery
-> inserted / engagement verification
```

### What is accepted now

| Accepted item | Current use |
|---|---|
| fixed Allen socket-head engagement | task definition |
| M8 source-canonical model | default geometry |
| RCIM 1-2 mm visual residual | source for visual-error sampling range, to be verified against local paper notes |
| RCIM 5 N spiral / 0.1 Nm threshold | source-inspired baseline, not our method |
| clearance / chamfer variables | controlled simulation variables |
| no true-center leakage | mandatory sampling and reporting rule |
| action-conditioned F/T | core learning input |
| source-style spiral | baseline and bootstrap search |

### What is deferred

| Deferred item | Reason |
|---|---|
| M10/M12 full benchmarks | scale variation after M8 loop works |
| M8/M10/M12 generalization claim | not supported by the first implementation |
| conical/nutation probe as default | optional disambiguation primitive after press/probe baseline |
| active information-gain planner | later research direction, not Stage-1 trigger |
| one contact probe plus CAD uniquely recovers center | observability claim not yet proven |
| outperforming the real RCIM robot system | only compare inside matched MuJoCo benchmark |

### Claim boundary after this decision

Allowed first-version claim:

```text
Under a known M8 Allen geometry and bounded visual residual error,
known low-force action primitives produce F/T signatures that can classify
contact events and guide conservative recovery toward engagement.
```

Not allowed:

```text
The system solves autonomous unscrewing.
The classifier predicts the true center.
M8/M10/M12 generalization is proven.
One conical probe plus CAD is enough to know the center.
Simulation proves real-robot success.
```

### Immediate implementation order

1. Build clean skeleton.
2. Port or reimplement only the source-canonical M8 geometry path.
3. Add visual-error offset sampling and log the sampled start points.
4. Implement source-style spiral / threshold baseline.
5. Generate M8 action-conditioned press/twist/lateral-probe dataset.
6. Train/report rule, KNN or small MLP baselines with confusion matrices.
7. Add conformal prediction sets and conservative routing.
8. Run a small gated recovery smoke.

### Notes for future expansion

M10/M12 geometry may be implemented early as parameterized model fixtures.
This has now been done in `src/allen_socket_model.py` and `models/allen_*_source.xml`.
The active evidence boundary still remains M8 until scale experiments are
actually run and summarized.

Conical, tilt, or nutation probes are plausible and may become a better active
sensing primitive than spiral. They must enter as a measured ablation:

```text
same initial offset distribution
same safety caps
same success / force / work metrics
same baseline comparison
```

## 2026-07-10 00:55 +08 - Conical Probe As Active Sensing, Not Center Oracle

### Context

After reviewing the conical / tilt-then-rotate contact-pose paper and discussing
the M8 top-view cases, the main ambiguity is:

```text
vertical touchdown can confuse outer-edge support, inner-rim support, chamfer
contact, and shallow insertion.
```

The useful idea from conical probing is not a single force reading. It is the
phase-structured F/T fingerprint generated by a small bounded active motion.

### Decision

Add a design stage:

```text
vertical touchdown
-> small conical / nutation fingerprint
-> macro state + circular direction belief + finite-coverage angular set
-> CAD-constrained feasible center sector + confidence + unsafe flag
-> biased guarded spiral or verify / retreat
```

The new design document is:

```text
docs/M8_CONICAL_PROBE_STATE_TRANSITION_DESIGN.md
```

### Boundary

Allowed:

- conical probing is a candidate active-sensing primitive;
- it may provide a calibrated direction distribution, angular set, and
  confidence for spiral search;
- CAD and contact state may turn that direction set into a feasible center
  sector, but not a unique true-center point;
- it must be evaluated against ordinary guarded spiral and an oracle direction
  upper bound.

Not allowed:

- one conical probe recovers the true center;
- conical probing replaces all spiral search before validation;
- conical probing is a proven real-robot method;
- the learned model directly controls the tool.

Do not introduce them by replacing the current pipeline silently.

## 2026-07-11 15:36 +08 - Use F/T state belief and approximate CAD as a soft radial likelihood

### Problem

The frozen P1v3 direction posterior is sharp on the same-start M8 case, but an
isotropic visual prior factorizes into angle and radius. Direction-only
reweighting therefore permits many candidate centers close to the current peg
position and limits conservative transport to 0.724 mm.

### Decision

Do not add an unconstrained learned distance head. Reuse the support-state
probabilities inferred from the same `Fz/Mx/My/tip-z` conical fingerprint and
combine them with approximate concentric CAD geometry:

```text
visual center candidates
* learned circular direction likelihood
* learned support-state probabilities
* soft CAD radial state likelihood
-> two-dimensional center posterior
-> capped conservative transport
-> coverage-preserving outward spiral
```

The M8 CAD boundaries are:

```text
full outer support: R_head - R_bit = 3.036 mm
inner-opening overlap limit: socket apothem + R_bit = 6.714 mm
```

Use logistic transitions with 0.35 mm sigma and a 0.02 floor. This keeps
manufacturing/model error and non-top state mass alive. The fusion must not use
the true center, MuJoCo contact points, or a radial training label.

### Same-case result and boundary

P1v3 predicts `double_overhang` with probability approximately one. Radial
q10/q50/q95 becomes 2.51/3.59/4.69 mm. The existing 1.50 mm transport cap is
active and residual coverage becomes 2.945 mm. CAD-bottom time/path/work improve
from direction-only 44.67 s / 79.77 mm / 140.16 mJ to 31.62 s / 45.89 mm /
83.81 mJ. Peak force worsens from 7.54 N to 22.43 N.

This is one synthetic-vision simulation case with a privileged capture tag. It
supports the interface mechanism only; it does not support a robustness,
hardware-safety, lower-wrench, or general-superiority claim. Preserve the old
direction-only videos as historical evidence.

## 2026-07-11 20:51 +08 - Correct the direct baseline and make active outputs explicit

### Audit finding

The old Jin-style video was a selected recovery stress illustration, not a fair
main baseline. It injected `+22.5/-22.5/0 deg` direction errors and used the true
initial offset magnitude to set direct travel. Comparing proposed against that
sequence would bias the conclusion.

### Decision

The active comparison has exactly three methods:

1. proposed: shared conical F/T -> frozen P1v3 direction/state -> vision + soft
   CAD posterior -> bounded transport -> local outward;
2. Baseline A: ordinary outward spiral with no probe cost;
3. Baseline B: the exact same conical F/T trace and frozen P1v3 direction as
   proposed -> direct ray up to the visual bound -> capture stop. Shifted reset
   plus full re-probe is the failure policy.

Baseline B receives no true center distance and no CAD radial likelihood. The
old scripted video is isolated under `outputs/current/diagnostics/`. The clean
paper-facing entry is `outputs/current/active_comparison/`.

### Result and consequence

All methods reach the same CAD-bottom endpoint in the selected `[4,0]` mm case.
Proposed and direct both command 179.59 deg. Direct wins: 11.22 s bottom time,
6.25 mm XY path, 15.93 mJ work proxy, and 4.72 N peak force, versus proposed
31.62 s / 45.89 mm / 83.81 mJ / 22.43 N. Ordinary outward is 54.39 s / 110.24
mm / 182.75 mJ / 6.12 N.

Therefore no single-case proposed-superiority claim is allowed. The proposed
local outward action must be evaluated where residual angular error, multimodal
direction, or boundary geometry can make the direct ray miss. Attempt one
succeeds here, so the retry branch is specified but not exercised by this video.

## 2026-07-12 - Freeze The Two-Funnel Interface And Four-Method Baseline Ladder

### Problem

The project had accumulated several partially overlapping stories: contact
state classification, exact-center estimation, assumed posterior videos,
ordinary spiral search, direct correction, and post-capture funnel control.
Some historical simulations also let MuJoCo contact tags participate in online
capture evaluation. This made it difficult to state one current closed loop.

### Decision

Freeze the paper mechanism as two coupled physical funnels:

```text
perception funnel:
visual prior -> one conical fingerprint -> circular direction/set
-> soft support-state x CAD radial likelihood -> bounded transport

execution funnel:
residual outward coverage -> sensor-only downward progress
-> upright tip-RCC / energy / CAD guarded insertion
```

The state head is action relevant but deliberately weak: it may only multiply
a soft CAD radial likelihood with a nonzero floor. It may not become a hard
state transition, millimeter distance command, capture trigger, or terminal
verifier.

The online controller may use F/T, pose/depth history, the visual prior, and
approximate CAD. True center and MuJoCo contact tags are offline scorers only.

### Frozen Baselines

| Method | Frozen role |
|---|---|
| A outward | no probe; ordinary Archimedean coverage from the visual anchor |
| B direct/retry | byte-identical first fingerprint/direction as Proposed; no state-CAD radius and no spiral fallback |
| C entropy grid | visual/CAD center belief; guarded low-force signed-F/T contacts chosen by expected entropy reduction; probe capture or unload/lift/shift/guarded posterior-mean touchdown; no spiral |
| Oracle | diagnostic upper bound only, excluded from the 2x2 active comparison |

All four active methods share the capture handoff, hard limits, and post-capture
guard. Baseline-B reset travel remains excluded from timing and must be
disclosed as a favorable bias. Baseline-C lift/shift/touchdown/dwell costs are
included. The old seeded random policy is retained only as an appendix
action-selection ablation.

### Evidence Boundary

The 36-pose pre-hardware audit gives Proposed/A/B/C eventual capture
34/30/28/22. Baseline B is fastest on common successes. Entropy-grid C uses a
median 7.5 guarded contacts, has zero hard stops, and is often cheaper on its
successful subset, but lacks coverage (P-only 13 versus C-only 1). Proposed's
defensible advantage is higher coverage from one learned fingerprint plus
residual/full outward fallback, not universal speed or path dominance.

### Hardware Data Decision

Do not collect a large real grid first. Use 12 low-force commissioning scans,
24 adaptation anchors, and 12 permanently untouched random scans. Only after a
documented failure may 12 active boundary/uncertainty samples be added. Freeze
the backbone first and prefer normalization, temperature, or a small adapter/
head. M10/M12 begin with zero-shot tests; their data does not enter M8 training
before transfer is measured.

## 2026-07-12 - Put Entropy Search After The Proposed+ Shortcut

### Problem

The first Proposed+ implementation executed two visually subtle entropy probes,
returned to the original contact anchor, and then reused the old Proposed
transport-plus-spiral tail. The resulting video looked like conical probe ->
straight line -> spiral, so the named entropy mechanism was neither visually nor
causally load bearing.

### Decision

Use the ordered policy:

```text
conical joint posterior
-> bounded shortcut
-> value-gated low-force entropy nodes with endpoint dwell
-> capture, or belief-health/VoI stop
-> guarded return to the shortcut anchor
-> residual outward fallback
```

Node-to-node motion keeps contact and follows spatial straight segments with a
minimum-jerk time law. Do not label intermediate moving samples. A single
non-contracting radius update is allowed because entropy and spatial credible
radius need not move monotonically together; two consecutive non-contracting
updates reject the grid posterior. The frozen conical plan remains the fallback
reference.

### Evidence Boundary

The selected `sobol_002` case now shows three entropy nodes before the spiral.
The grid posterior is rejected, local fallback completes at CAD bottom, and no
global fallback or hard stop occurs. Proposed+ is slower than Proposed and C in
this case. Keep it experimental until a fresh paired audit establishes whether
the added contacts buy coverage or efficiency.

## 2026-07-12 - Replace Pure Entropy With Task-Aware Belief-Grid Control

### Problem

Maximum expected entropy reduction is a localization objective. It can prefer a
diagnostic boundary point that is far from the most likely capture corridor. A
subsequent local spiral then becomes load bearing again, which defeats the
purpose of combining the conical fingerprint with active contact.

### Decision

Assign different roles to the available information: vision initializes center
belief, the conical fingerprint supplies a tempered direction/state likelihood,
and CAD defines support geometry, the capture tube, and observation likelihood.
Select each low-force grid segment by

$$
U(\mathbf g)=w_cP_{cap}([\mathbf x_k,\mathbf g]\mid b_k)
+w_I\,I(\mathbf h;y\mid\mathbf g)
-\lambda_l\|\mathbf g-\mathbf x_k\|-C_{contact}.
$$

Treat a no-capture segment as soft negative evidence over the swept CAD capture
tube. Temperature-downweight an F/T class whose predictive probability is low.
Disable the local spiral in Proposed+; retain full visual-support outward
coverage only as a separately counted last resort. Capture preempts every
tangential action and enters the shared post-capture funnel.

### Why This Is Physically Consistent

The objective values task progress and observability separately. The peg has
finite width, so capture belongs to the swept segment rather than an idealized
endpoint. Grid pitch must satisfy $h_g/\sqrt 2\leq r_{eff}$; for M8 the current
0.3359 mm action pitch is below the 0.3536 mm bound for
$r_{eff}=0.25$ mm. The simulated F/T model is not trusted enough to erase a
geometrically feasible center, which is essential for later iiwa fine tuning.

### Evidence Boundary

The selected `sobol_002` rollout captures during task-grid segment 3 at 9.828 s
and reaches CAD bottom at 11.696 s, without local or global spiral fallback.
The first 12 Sobol poses are a development set, not an independent test. Keep
Proposed+ experimental until the untouched holdout and paired hardware audit are
reported.

## 2026-07-12 - Make Capture Preemption Direction Consistent And Bumpless

### Problem

The first untouched Proposed+ holdout exposed two distinct controller faults:

1. local-grid exhaustion restored full down-force or a fixed search-plane Z
   before the global reset was complete, producing two hard stops;
2. the depth/F/T gate could interpret a drop down the outer head wall as socket
   inner-wall capture.

### Decision

Keep the low-force, low-impedance state through the return to the visual anchor.
Ramp force and impedance continuously only after the anchor is stable, and start
the fallback path at the current nominal Z. Capture cues preempt the return
itself.

For methods that own a conical direction estimate, accept a depth/F/T candidate
only when

$$
(\mathbf x_c-\mathbf x_0)^\top\hat{\mathbf u}_{top1}\geq-r_{eff}.
$$

This rejects only candidates materially behind the sensed hole direction. It
does not estimate the center and does not use MuJoCo labels or the true center.
The tolerance is the CAD top-capture radius, not a tuned success threshold.

### Evidence Boundary

On the fault-discovery tasks, the two outer-wall false cues had projected
progress -2.12/-1.50 mm while all strict true captures were at least +1.44 mm.
The same-task regression becomes 35/36 with zero hard stops; one case honestly
ends in `search_radius_exhausted`. Because these tasks informed the repair, that
result is diagnostic only.

The frozen seed-20260723 fresh validation gives strict captures
21/23/23/22/23 for Proposed+/Proposed/A/B/C, all with zero hard stops.
Proposed+ reduces median path/wear relative to Proposed on common successes, but
is slower, has two fewer strict captures, and is less contact-efficient than C.
It remains an experimental branch. Three near-boundary failures continue to CAD
bottom in 0/3 cases, so the physical funnel is not a rescue guarantee.
## 2026-07-12 - Keep Proposed As The Main Method

Decision:

- retain one conical fingerprint, bounded posterior transport, residual/full
  outward coverage, and shared safe insertion as the paper-facing Proposed
  method;
- keep Proposed+ capture-plus-information grid segments as an experimental
  action-selection ablation.

Reason:

- the physical hinge is the one-shot direction likelihood, not the number of
  planning modules;
- fresh M8 validation does not show a success/time advantage for Proposed+;
- making the experimental branch the main method would add repeated contacts
  without stronger distribution evidence.

## 2026-07-15 - Return The Paper-Facing Ladder To Four Methods

Decision:

- use Proposed / Baseline A outward / Baseline B shared-direction direct-retry /
  Baseline C seed-fixed random as the only paper-facing 2x2 ladder;
- use `m8_four_method_sensor_only_audit` as the matching 36-pose frozen report;
- downgrade the six-method matrix, the Proposed+/Proposed/entropy race, and the
  entropy-grid branch to historical or deferred action-selection evidence;
- keep the post-capture funnel guard as a separate safety ablation shared by
  every search policy.

Reason:

- the four methods isolate the current load-bearing questions without adding a
  second, insufficiently validated information-planning contribution;
- random is a transparent unstructured lower bound and may win by luck in one
  selected seed, so method claims remain tied to paired multi-pose statistics;
- entropy-grid remains technically interesting, but it is not needed to close
  the present fingerprint-to-search-to-physical-funnel paper story.

## 2026-07-15 - Supersede The Historical Four-Method Ladder With The Strict Contract

This decision supersedes the preceding four-method/capture-only media decision.

Decision:

- use the frozen strict-24 seven-role report for distribution claims: Proposed,
  Proposed+, Outward, Entropy-grid, Direct-first, Random and Oracle;
- use two same-order selected 2x2 mechanism videos only: Proposed+, Proposed,
  pure Outward and Direct-first, for one fuzzy/short and one clear/long case;
- keep Proposed as the paper-facing method and Proposed+ as a research branch
  with no superiority claim;
- exclude historical direct/retry from the strict ladder because simulator
  reset motion/time was not charged; Direct-first is exactly one ray;
- retain Entropy-grid as a strong transparent aggregate diagnostic, not a weak
  baseline. Its padded lattice is the only current finite-domain node-geometry
  certificate;
- call finite Outward a dense empirical search comparator, not a complete-disk
  coverage certificate, because it has no padded outer boundary.

Reason:

- the strict contract aligns initial state, nuisance, sensor seed, handoff,
  terminal verifier and a non-extendable 130 s active budget;
- the two matrices explain how fingerprint quality changes shortcut length and
  first-ray outcome, while the frozen batch remains the only method-level
  evidence;
- post-hoc clear/long and fuzzy/short strata cover only 11/24 extreme cases and
  are descriptive, not probability estimates.
